# Скрипты сборки сценария

Пути внутри скриптов захардкожены на `sessions/konkurentnaya-razvedka` — при переносе на другой
проект поправить константу `D` в начале каждого файла.

| Скрипт | Что делает | Запуск |
|---|---|---|
| `build_gates_html.py` | avatar.md / tov.md → читаемые HTML + навигация между страницами | `python3 build_gates_html.py` |
| `rebuild_review.py` | пересобирает `review.html` из `.blocks/*.json`: пересчёт таймкодов, версия в ярлык И в ключ localStorage | `python3 rebuild_review.py v11` |
| `build_v9.py` | сборка сценария из результата воркфлоу. **Гейты ДО записи**: комплектность, дубли между блоками, стоп-слова, «ты», одна интеграция | `python3 build_v9.py` |
| `numerals.py` | числа прописью → цифрами. dry-run по умолчанию | `python3 numerals.py [--apply]` |
| `scan_claims.py` | вытаскивает все цифровые утверждения из суфлёра — для фактчека | `python3 scan_claims.py` |
| `apply_facts.py` | образец точечных правок по всем файлам сразу + гейт на остатки запрещённого | — |

## Грабли, зашитые в скрипты (не сломай)

1. **`rebuild_review.py`** использует `lambda` в `re.subn`, а НЕ строку замены. `re` трактует `\n`
   в replacement как escape и рвёт JSON внутри HTML. Скрипт падает, если не найдёт
   `SCENARIO_VERSION` — это защита: без версии в ключе localStorage браузер вернёт ответы прошлой
   версии, и уже внесённые правки приедут как новые.
2. **`build_v9.py`** не пишет файлы, если гейты красные. Так и задумано: дважды блоки молча
   пропадали из воркфлоу и затирали рабочие файлы.
3. **`numerals.py`** держит множитель словом («150 миллиардов», не «150 000 000 000») — это суфлёр,
   его читают вслух. Есть список EXPLICIT для случаев, где автомат бессилен (дроби, годы, эллипсис).
