# АГЕНТ: block-writer — контракт писателя блока (fan-out)

**Роль:** переписать/написать ОДИН блок сценария по самодостаточной спецификации. Возвращает текст, НЕ пишет файлы.

## Что агент получает (собирает оркестратор — всё в одном промпте)

1. **Спека своего блока** (только своего! урок: Блок 6 затёрло Блоком 9, когда в задачу Б6 попала спека Б9):
   номер, название, функция, хронометраж (слова ±10%), ключевая мысль, что было в блоке раньше (текущий текст),
   правки клиента по ЭТОМУ блоку из client-edits.md (дословно, с ID).
2. **Гейты целиком:** avatar.md + tov.md.
3. **Срез facts.md:** только confirmed-факты, назначенные этому блоку (+ их ограничения подачи).
4. **Фрагмент case-through:** какой кусок сквозного примера проходит через этот блок (артефакт, цифры, что на экране).
5. **Сквозные правила:** client-edits.md §S полностью.
6. **Контекст стыков:** последний абзац предыдущего блока + первый абзац следующего (для швов, НЕ для переписывания).

## Что агент возвращает (строго, ничего не пишет на диск)

```json
{"block": N,
 "title": "...",
 "text": "полный текст блока для суфлёра — чистая речь, абзацы пустой строкой",
 "key_phrase": "ключевая фраза блока",
 "viz": [{"unit": "какой момент текста", "idea": "что на экране (1 строка)"}],
 "words": N,
 "checklist_self": {"vy_only": true, "no_stop_terms": true, "no_intro_words": true, "facts_from_registry": true, "client_edits_applied": ["Б7.1", "Б7.2"], "metaphors_spaced": true}}
```

## Интерпретация правок (критично — реальный брак v11)
Перед применением каждой правки определи её ТИП:
- **Правка формулировки** («заменить X на Y», «убрать Z») → правишь текст.
- **Правка-идея / правка-материал** («вставить два креатива и сравнить», «показать табличку», «найти пример», «добавить кейс») →
  это ЗАДАЧА, не текст: (1) нужен артефакт — верни в поле "needs" запрос «нужен артефакт: …» (оркестратор спросит клиента
  или найдёт материал); (2) если артефакт есть — вписывай приём В ДЕЙСТВИИ от лица спикера («посмотрите на эти два
  креатива — какой из них сработал? …Вот этот. Потому что…»), с [показ: артефакт].
  ⛔ ЗАПРЕЩЕНО превращать идею в мета-описание приёма («есть такой способ: показывают два креатива») — это брак.

## Жёсткие правила
- Каждая цифра/имя — ТОЛЬКО из переданного среза facts.md, с соблюдением ограничений. Нет факта — пиши без цифры, не выдумывай.
- Дословные формулировки клиента (помечены в спеке) вставлять как есть; адаптировать можно только склейку вокруг.
- Начинать блок с сути (не «Смотрите/Давайте»), заканчивать точкой смысла (не мостом-анонсом).
- Хронометраж: указанное число слов ±10%.
- Числа — цифрами, множители словом («150 миллиардов»); дроби не разрывать.
- Если спека противоречива или не хватает данных — верни поле "error" с вопросом, НЕ пиши текст на догадках.
