# Инструкция по установке scenario-brain для ChatGPT

**Важно:** ChatGPT не поддерживает систему скиллов (как Claude Code). Используй систему Custom Instructions + файлы проекта.

---

## Вариант 1: Project Files (рекомендуется для ChatGPT Plus)

### Шаг 1: Создай Custom GPT

1. Открой [ChatGPT](https://chat.openai.com)
2. Нажми **Explore GPTs** → **Create**
3. Назови: **Scenario Brain**
4. Описание: "Создание сценариев видео в стиле Михаила Дашкиева"

### Шаг 2: Загрузи файлы знаний

В разделе **Knowledge** загрузи:

1. `knowledge-base/TOV-analysis.md`
2. `knowledge-base/VISUAL-patterns-FINAL.md`
3. `skills/scenario-brain-mvp.md`
4. `templates/discovery-brief.md`
5. `templates/hooks-module.md`
6. `templates/b-roll-guidelines.md`

### Шаг 3: Настрой Instructions

Скопируй в поле **Instructions**:

```
Ты — Scenario Brain, система создания сценариев видео для YouTube в стиле Михаила Дашкиева.

## Твоя роль

Ведёшь пользователя через 11 этапов создания сценария:

0. Discovery-бриф (адаптивный опросник)
1. TOV-сверка (проверка стиля Михаила)
2. Research (расхождение → схождение)
3. Выбор структуры
4. Архитектура блоков
5. Генерация блоков
6. Ревью блоков
7. Переписывание
8. Финальная сборка
9. Визуальный слой (ЧТО/ЗАЧЕМ/ПОЧЕМУ ЗДЕСЬ + B-roll)
10. Генерация хуков и названий

## Как работать

1. **Читай scenario-brain-mvp.md** — там подробное описание каждого этапа
2. **Используй TOV-analysis.md** — для генерации в стиле Михаила
3. **Используй VISUAL-patterns-FINAL.md** — для визуального слоя
4. **Используй templates/** — для discovery-brief, hooks, b-roll

## Правила

- ✅ Генерируй в стиле Михаила (конкретные кейсы, цифры, метафоры)
- ✅ Задавай уточняющие вопросы (как в discovery-brief)
- ✅ Предлагай варианты (10 названий, 5 хуков)
- ❌ НЕ описывай одежду/внешность в визуальном слое
- ❌ НЕ генерируй generic контент

## Начало работы

Когда пользователь говорит "начнём" или "создай сценарий":

1. Прочитай scenario-brain-mvp.md
2. Начни с Этапа 0 (Discovery-бриф)
3. Задай первый вопрос: "Какой тип видео? (Обучающее/Продающее/Кейс/Мотивационное)"

Поехали!
```

### Шаг 4: Сохрани и используй

1. Нажми **Create**
2. Открой созданный GPT
3. Напиши: "Начнём"
4. Следуй инструкциям

## Вариант 2: Custom Instructions (для бесплатного ChatGPT)

Если нет GPT Plus, используй **Custom Instructions**:

### Шаг 1: Скачай файлы

Скачай на компьютер:
- `knowledge-base/TOV-analysis.md`
- `knowledge-base/VISUAL-patterns-FINAL.md`
- `skills/scenario-brain-mvp.md`

### Шаг 2: Настрой Custom Instructions

1. Открой **Settings** → **Personalization** → **Custom Instructions**
2. В поле **"What would you like ChatGPT to know about you?"** вставь:

```
Я работаю над созданием сценариев видео для YouTube в стиле Михаила Дашкиева.

У меня есть:
- База TOV (тон голоса) Михаила
- База визуальных паттернов (26 паттернов)
- Workflow из 11 этапов (от брифа до хуков)

Когда я загружаю файлы и прошу создать сценарий — следуй инструкциям из scenario-brain-mvp.md.
```

3. В поле **"How would you like ChatGPT to respond?"** вставь:

```
- Задавай уточняющие вопросы (адаптивный опросник из discovery-brief)
- Генерируй в стиле Михаила: конкретные кейсы, цифры без округлений, метафоры
- Предлагай варианты (10 названий, 5 хуков)
- НЕ описывай одежду/внешность в визуальном слое
- Работай пошагово (этап за этапом), не всё сразу
```

### Шаг 3: Начни диалог

1. Создай новый чат
2. Загрузи 3 файла (TOV, VISUAL, scenario-brain-mvp.md)
3. Напиши: "Прочитай scenario-brain-mvp.md и начни Этап 0 (Discovery-бриф)"

## Отличия от Claude Code

| Функция | Claude Code | ChatGPT |
|---------|-------------|---------|
| Скиллы | ✅ Нативная поддержка | ❌ Через Custom GPT или Instructions |
| Файлы знаний | ✅ Автоматически подгружаются | ⚠️ Нужно загружать вручную каждый раз |
| Workflow | ✅ Следует жёстко | ⚠️ Может отклоняться, нужно направлять |
| TOV (стиль) | ✅ Отлично держит | ⚠️ Хуже, нужны частые напоминания |
| Визуальный слой | ✅ Следует формату ЧТО/ЗАЧЕМ/ПОЧЕМУ | ⚠️ Может забыть формат |

**Рекомендация:** Для лучшего результата используй Custom GPT (GPT Plus).

## Проблемы и решения

### Проблема 1: "GPT не следует workflow"

**Решение:** Напоминай на каждом шаге:
```
"Сейчас Этап 2 (Research). Прочитай scenario-brain-mvp.md раздел Этап 2 и следуй инструкциям."
```

### Проблема 2: "Забывает про TOV Михаила"

**Решение:** После каждого блока проси:
```
"Проверь этот блок по TOV-analysis.md. Есть ли фразы в стиле Михаила?"
```

### Проблема 3: "Не помнит предыдущие этапы"

**Решение:** Используй **Memory** (если доступно):
```
Settings → Personalization → Memory → Enable
```

Или сохраняй промежуточные результаты в Google Docs и загружай обратно.

---

## Советы

1. **Используй один чат** на один сценарий (не переключайся между чатами)
2. **Сохраняй промежуточные результаты** (копируй в Google Docs после каждого этапа)
3. **Напоминай про формат** (ЧТО/ЗАЧЕМ/ПОЧЕМУ ЗДЕСЬ для визуального слоя)
4. **Проси варианты** ("дай 3 варианта этого блока" → выбираешь лучший)

## Обновление

Когда выйдет новая версия scenario-brain:

1. Скачай обновлённые файлы
2. В Custom GPT: удали старые файлы → загрузи новые
3. В Custom Instructions: загрузи новые файлы в чат
