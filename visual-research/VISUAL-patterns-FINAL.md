### A2. За столом
**Сложность:** Низкая | **Частота:** 20%
- Деревянный стол, чашка кофе
- Более камерная атмосфера
- Примеры: v5-02, v7-01

### A3. Окно с городом
**Сложность:** Средняя | **Частота:** 5%

# ЧАСТЬ 3: Система матчинга (текст → визуал)

## Как выбирать визуал для конкретных слов/фраз

### Шаг 1: Парсинг сценария на семантические единицы

Сценарий разбивается на:
- **Блоки** (хук, основа, финал)
- **Предложения** (каждое предложение = потенциальный кадр)
- **Ключевые слова** (триггеры визуализации)

### Шаг 2: Определение визуальных триггеров

| Триггер в тексте | Тип визуала | Паттерн |
|------------------|-------------|---------|
| "3 шага", "4 типа" | Список | B1, B4 |
| "Кризис = протокол" | Ключевая фраза | B2 |
| "М.Видео", "Airbnb" | Кейс компании | D1 + C1 |
| "20 млрд убытка" | Цифра/статистика | C1 |
| "как пружина", "как монолит" | Метафора | E1, F5 |
| "Bennis говорил..." | Цитата | F3 (исторический коллаж) |
| "страх", "паника", "боль" | Эмоция | F1 (киношный футаж) или F5 (стильная метафора) |
| "мозг работает так..." | Биология/наука | F2 (3D-рендер) |
| "выбирай сам" | Интерактивность | F4 (3D персонаж + UI) |
| "два пути" | Сравнение | Split-screen или F6 (рисованная) |

### Шаг 3: Матчинг паттерн + опциональный референс

Для каждого триггера:
1. **Выбирается базовый паттерн** (из проверенных)
2. **Опционально предлагается референс** из библиотеки (если хочется улучшить)

**Пример:**

```markdown
**Текст:** "Кризис бьёт по компании как молния"

**Триггер:** Метафора (молния)

**Паттерн:** F5 (Стильная анимированная метафора)
- Фиолетовый силуэт компании
- Анимация молнии сверху

**Опциональный референс:**
- Motion Array: "Lightning Strike Logo Reveal"
- Или Midjourney: "lightning strikes abstract company building, purple and black, minimalist --ar 16:9"
```

## Формат выхода: visual-layer.md

Для каждого блока сценария генерируется:

```markdown
### Блок 3: Финансовая диагностика (12:00-17:00)

#### Кадр 1: Говорящая голова (12:00-12:30)
**Текст:** "Первое, что нужно сделать в кризисе — это честная финансовая диагностика."
**Визуал:** A1 (Студийная говорящая голова)
**Длительность:** 30 сек

#### Кадр 2: Таблица с показателями (12:30-12:50)
**Текст:** "Четыре ключевых показателя: выручка, EBITDA, долг, запас прочности."
**Триггер:** Список (4 показателя)
**Визуал:** C1 (Таблица с метриками)
**Детали:**
- Левая половина: офисный B-roll (человек за компьютером с калькулятором)
- Правая половина: таблица
  - Строки: Выручка | EBITDA | Долг | Запас прочности
  - Колонки: Показатель | Норма | У вас | Статус
  - Цвета: зелёный = норма, красный = проблема
**Длительность:** 20 сек

**Опциональный референс:**
- Motion Array: "Corporate Data Table Pack" (AE template)
- Или создать в After Effects вручную

#### Кадр 3: Метафора — пружина vs монолит (12:50-13:10)
**Текст:** "Антихрупкая компания — как пружина. Хрупкая — как монолит."
**Триггер:** Метафора (пружина vs монолит)
**Визуал:** F5 (Стильная анимированная метафора)
**Детали:**
- Split-screen: левая = монолит трескается, правая = пружина сжимается
- Стиль: минималистичная 2D анимация
- Цвета: фиолетовый + чёрный

**Опциональный референс:**
- Midjourney: "minimalist animation, spring vs solid block, purple and black, split screen --ar 16:9 --style raw"
- Или Motion Array: "Abstract Shape Comparison Template"

**Альтернативный вариант (если хочется киношно):**
- F1 (Киношный футаж) через Runway Gen-3
- Промпт: "Close-up of metal spring compressing under pressure, then bouncing back. Cinematic lighting, slow motion"
**Длительность:** 20 сек
```

## Workflow Этапа 10: Визуальный слой

### Вход:
- `final-scenario-v2.md` (текст сценария)
- `VISUAL-patterns-FINAL.md` (эта база)

### Процесс:

1. **Читаю сценарий блок за блоком**
2. **Для каждого предложения:**
   - Парсю на триггеры (метафора, список, цифра, кейс, эмоция)
   - Матчу триггер → паттерн (из таблицы выше)
   - Генерирую описание кадра
3. **Добавляю опциональные референсы:**
   - Если триггер = метафора → предлагаю Midjourney промпт
   - Если триггер = таблица → предлагаю Motion Array шаблон
   - Если триггер = эмоция → предлагаю Runway Gen-3
4. **Рассчитываю таймкоды:**
   - Длина текста блока → примерное время чтения
   - Добавляю время на визуал (5-20 сек)
5. **Сохраняю в `visual-layer.md`**

### Выход:
- `visual-layer.md` — детальные инструкции для монтажёра
- Для каждого кадра:
  - Таймкод
  - Текст (что говорит Михаил)
  - Паттерн (какой визуал)
  - Детали (как именно показать)
  - Опциональный референс (откуда взять пример/шаблон)

## Критерии выбора визуала

### Простой vs Сложный

**Простой паттерн** (B1, B2, D1) → когда:
- Бюджет ограничен
- Сроки горят
- Контент не требует вау-эффекта

**Сложный паттерн** (F1-F6) → когда:
- Ключевой момент видео (хук, кульминация)
- Нужно удивить зрителя
- Есть бюджет на 3D/AI-генерацию

### Проверенный vs Новый

**Проверенный** (A-E) → по умолчанию
- Команда уже делала
- Быстро реализуется
- Стиль канала

**Новый** (F1-F6 + референсы) → когда:
- Хочется экспериментировать
- Тема требует нового подхода
- Есть время на тест
