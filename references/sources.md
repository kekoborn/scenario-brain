# Sources — курируемый реестр источников фактуры

Используется на **Этапе 1 (Research)** и **Этапе 10 (артефакты-доказательства)**.

## Как пользоваться
- `[NLM]` — источник грузим в NotebookLM (`notebooklm source add <url>` / `source add-research "<запрос>"`),
  потом `ask "..." --json` → берём ответ + `references[].source_id`.
- `[свой источник]` — кандидат на прямой доступ к данным / мини-pipeline. **Не зашит заранее** —
  подбирается под конкретную тему и только после подтверждения пользователем (Этап 1, Фаза 0).
- Любой факт всё равно проходит **гейт источника** (см. `research-rules.md`): цифра/имя/кейс — только
  с `source_id` или `URL + дата`. Нет источника → не используем.
- Перед поиском всегда сверяемся с пользователем: точно ли по этим темам и нужны ли отдельные источники.

## Категория 1. Бизнес-кейсы РФ (компании, факты, упоминания)
- `[NLM]` СМИ для СМИ-первоисточника упоминания: rbc.ru, vc.ru, forbes.ru, kommersant.ru, rb.ru.
- `[NLM]` Карточки компаний: rusprofile.ru, list-org.com, Федресурс (fedresurs.ru).
- `[свой источник]` Если нужны финданные/реестры напрямую — подобрать/собрать pipeline под задачу.
  Приём: открытые API госреестров вместо парсинга сайта (быстрее и стабильнее, чем скрейпинг).
- Готовые гугл-запросы боту: «<компания> выручка <год> отчётность», «<компания> новость <тема>».

## Категория 2. Мировые бизнес-кейсы
- `[NLM]` hbr.org, bloomberg.com, techcrunch.com, ft.com, reuters.com.
- Загружаем конкретные статьи под тезис; общий веб-поиск — для нахождения нужной статьи.

## Категория 3. Статистика рынков
- `[NLM]` Statista (публичные релизы), отраслевые отчёты (профильные ассоциации), Росстат, ЦБ РФ.
- Правило свежести (`research-rules.md`): рыночная статистика — только текущий/прошлый год.

## Категория 4. Банкротства и конфликты партнёров
- `[NLM]` Федресурс (банкротства), kad.arbitr.ru (карточки арбитражных дел), СМИ-разборы корпконфликтов.
- Готовые запросы: «компании закрылись из-за конфликта учредителей», «<имена> разошлись партнёры бизнес».
- Фото реальных людей — только из публичных СМИ-материалов, **со ссылкой на источник + дата**.

## Категория 5. Артефакты для визуала (Этап 10)
- Кадры из фильмов/сериалов: kinopoisk.ru, imdb.com, getyarn.io, frinkiac.com (поиск по реплике).
- Мемы: knowyourmeme.com (берём с указанием первоисточника/даты мема).
- Нейтральный b-roll/сток: Pexels, Unsplash, Storyblocks — **это НЕ доказательство**, а фон/иллюстрация.

## Охота за артефактами (Этап 10.3) — рецепты поиска материалов

Под каждый визуальный якорь скилл **сам** находит реальный материал. Складываем в `assets.md`,
превью ключевых качаем в `sessions/[project]/assets/`. Гейт источника обязателен.

**Лого компании/бренда:**
- Быстро: `https://logo.clearbit.com/<домен>` (напр. `logo.clearbit.com/12storeez.com`) — отдаёт PNG.
- Надёжно: официальный сайт (favicon / press-kit / `og:image`), Wikimedia Commons (файл лого).
- Запрос боту: «<бренд> logo png», «<бренд> пресс-кит», «<бренд> brand assets».

**Скрин сайта / страницы (универсально, встраиваемая картинка):**
- mShots: `https://s.wordpress.com/mshots/v1/<URL-encoded>?w=600` — рендерит скриншот любой
  страницы по URL. Так показываем **сайт компании**, витрину-через-сайт, **скрин статьи-пруфа**
  и профильную статью о человеке. Прямая картинка — кладём `src` в борд.

**Фото человека (основатель / эксперт / автор):**
- Wikimedia Commons (свободная лицензия — указать её) — приоритет для публичных персон (Талеб, Беннис).
- Публичные СМИ (интервью Forbes/vc/РБК): фото = `og:image` статьи (вытащить из `<head>`) со ссылкой + дата.
  Если прямой URL картинки не вытаскивается — mShots-скрин профильной статьи.
- **Несколько сооснователей → фото ВСЕХ** (Хохлов + сёстры Голомаздины у 12 STOREEZ; не одного).
- Запрос: «<имя> фото интервью <издание>», «<name> portrait wikimedia». Приватные соцпрофили **не берём**.

**Скрин СМИ-первоисточника под цифру/кейс:**
- Берём ровно ту статью из `research-insights.md`, где стоит цифра (URL+дата) → mShots-скрин страницы.
- Запрос (если ссылки нет): «<цифра/факт> <тема> <издание> <год>». Нет живого источника → флаг ⚠️ (не выдавать за факт).

**Обложка книги / товар:**
- Издатель / маркетплейс: прямой URL картинки (og:image / галерея товара). HBR / исследование — mShots-скрин страницы.

## Творческий слой — футаж и генерация (опционально)

Ядро Этапа 10 — **реальные материалы выше** (лого / скрин сайта / фото всех собственников / пруф-скрин).
Внешние реф-базы кадров (Shot Cafe, Film Grab, MovieStillsDB) и редакторы раскадровки
(Storyboarder, Krock, Storyflow) в основной поток **НЕ входят** — подключаем, только если команда
сама попросит. Что остаётся полезным под поле «образ → как сделать»:
- **Футаж / b-roll (бесплатно):** Pexels Video, Mixkit, Coverr, Videvo, archive.org, YouTube CC;
  платно (охват) — Storyblocks, Artgrid.
- **Генерация образа:** на выходе даю **готовый ген-промпт** под кадр (свет / оптика / камера) для
  Runway / Kling / Midjourney; словарь стиля — PromptSpace / Promptomania (в борд кладу сам промпт, не ссылку).

## Запреты
- Цитата / цифра без даты и ссылки — не использовать.
- Репост / скриншот без выхода на первоисточник — не доказательство.
- Сгенерированное «правдоподобное» фото реального события/человека вместо реального — запрещено.
- Лицо человека из приватного соцпрофиля вместо публичного СМИ/Commons — не брать.
