## G. Артефакты-доказательства (РЕАЛЬНЫЕ, со ссылкой)
**Приоритет над абстрактной генерацией.** Под кейс/факт/метафору сначала ищем реальный объект,
а не рисуем иконку. Источники — `references/sources.md`. У каждого артефакта обязательна
ссылка-первоисточник (URL + дата); без неё — пометка `⚠️ источник не найден` монтажёру.

| Код | Тип артефакта | Где искать (sources.md) | Паттерн показа |
|-----|---------------|-------------------------|----------------|
| G1 | Скрин СМИ-упоминания (кейс/цифра) | §1–2 (РБК, Forbes, HBR…) | C2 overlay / D1 split |
| G2 | Фото реального человека/лица | §4 (публичные СМИ) | D1 split / F3 коллаж |
| G3 | Кадр из фильма/сериала под образ/эмоцию | §5 (kinopoisk, getyarn) | D1 / F1 |
| G4 | Мем (с первоисточником) | §5 (knowyourmeme) | B2 overlay / D1 |
| G5 | Скрин отчётности/реестра (цифры) | §1, §3 | C1 / C2 |

> **Не путать два набора:** `visual-research/` — это про **стиль съёмки ведущего** (как снимать
> Мишу: ракурс, свет, графитово-фиолетовая палитра). Секция G — это **что показать как
> доказательство тезиса** (реальный артефакт со ссылкой). Первое — форма, второе — содержание.

## Правила
✅ Описывать: **реальный артефакт-доказательство под тезис (приоритет, секция G)**, композицию
(split/overlay/PiP), объекты и движение, смысловую нагрузку, цвета/формы, референс-направление,
3–4 B-roll варианта + рекомендацию.
❌ НЕ описывать: одежду, причёску, аксессуары, внешность ведущего, технические параметры
анимации (keyframes/fps). **Не давать абстрактную иконку там, где есть реальный артефакт.**

Визуализировать **по смысловым фразам** (3–10 на блок), не блок одним куском. Для длинного
видео (>15 мин) — навигатор-прогресс (B4), повторять главный месседж визуально 2–3 раза.
