# STRUCTURES Analysis — 5 архитектур видео Михаила Дашкиева

Анализ структур на основе реальных выступлений и видео.

---

## Структура 1: Протокол / Checklist (пошаговая инструкция)

### Описание
Видео построено как последовательность конкретных шагов: делай 1→2→3→4, получишь результат.

### Когда использовать
- Обучающее видео (протокол действий)
- Зритель уже в проблеме, нужно действовать прямо сейчас
- Есть чёткая последовательность шагов
- Задача — дать инструмент "на вынос"

### Структура

**1. Хук (2-3 мин)**
- Через ошибку: "Вот что НЕ надо делать"
- Или через боль: "Вы сейчас в такой ситуации?"

**2. Главная рамка (3-5 мин)**
- Объяснение концепции
- Почему это протокол, а не хаос
- Обещание результата

**3. Шаги протокола (20-30 мин)**
- Шаг 1: Что делать + пример + почему
- Шаг 2: Что делать + пример + почему
- ...
- Шаг N: Что делать + пример + почему

Каждый шаг:
- Конкретное действие
- Пример (кейс или метафора)
- Обоснование (почему важно)

**4. Промежуточные итоги (каждые 10 мин)**
- "Что мы сделали?"
- "Что дальше?"

**5. Финал (3-5 мин)**
- Что получает зритель, если пройдёт протокол
- Call to action (скачать чек-лист, применить)

### Пример из практики Михаила
- Антикризисный протокол (12 шагов)
- Протокол найма
- Стратегическая сессия: пошаговка

### Плюсы
✅ Практичность — можно сразу применить  
✅ Структурированность — легко следить  
✅ "Настольное видео" — можно пересматривать по шагам  

### Минусы
⚠️ Может быть длинным (40+ минут)  
⚠️ Требует высокой концентрации зрителя  
⚠️ Нужна визуальная навигация (чек-лист на экране)  

### Как держать внимание
- Промежуточные итоги каждые 10 минут
- Визуальный чек-лист (галочки по шагам)
- Кейсы между шагами (чтобы не было сухо)

## Структура 2: Хаос → Диагностика → Решение

### Описание
Эмоциональная арка: от паники к протоколу. Зеркалит состояние зрителя.

### Когда использовать
- Зритель в кризисе, паникует
- Нужно сначала "отзеркалить" его состояние
- Важна эмоциональная вовлечённость

### Структура

**1. Хук (2-3 мин)**
- "Вы в хаосе прямо сейчас"
- Узнаваемая боль

**2. Хаос (5-7 мин)**
- Что происходит с компанией в кризисе
- Типичные ошибки
- Паника, метания
- Кейсы провалов (М.Видео, Кофтёнышки)

**3. Диагностика (10-12 мин)**
- Как понять, где вы
- Точка безубыточности
- Сценарии (спасать/анабиоз/закрыть)
- "Вот где вы находитесь"

**4. Решение (15-20 мин)**
- Антикризисный протокол
- Конкретные шаги
- Примеры действий

**5. Трансформация (5-7 мин)**
- Из хаоса в антихрупкость
- Кейсы успеха (Airbnb)
- Высокая нота

**6. Финал (2-3 мин)**
- Call to action

### Пример из практики
- Видео про кризис 2020
- Выступления на конференциях в турбулентные периоды

### Плюсы
✅ Эмоциональная вовлечённость  
✅ Зритель чувствует "меня поняли"  
✅ Драматургия (легче держать внимание)  

### Минусы
⚠️ Может быть слишком эмоциональным (не хватит конкретики)  
⚠️ Зритель может застрять в блоке "Хаос"  
⚠️ Риск потерять практичность  

### Как держать баланс
- Быстро пройти блок "Хаос" (5-7 мин max)
- Сразу дать надежду: "Вот что делать"
- Больше времени на "Решение", чем на "Хаос"

---

## Структура 3: Ошибка → Контраст → Протокол → Результат

### Описание
Начинаем с узнаваемой ошибки, показываем контраст (провал vs успех), даём протокол.

### Когда использовать
- Есть яркие кейсы провала и успеха
- Нужно показать "вилку" (что будет, если делать vs не делать)
- Зритель может не осознавать проблему

### Структура

**1. Хук (2-3 мин)**
- Типичная ошибка, которую все делают
- "Вот что НЕ надо делать"

**2. Пример провала (5-7 мин)**
- Кейс компании, которая сделала ошибку
- М.Видео, Кофтёнышки
- Конкретные цифры убытков

**3. Пример успеха (5-7 мин)**
- Кейс компании, которая сделала правильно
- Airbnb
- Конкретные цифры роста

**4. Контраст (3-5 мин)**
- В чём разница?
- Паника vs Протокол
- Что изменилось в подходе?

**5. Протокол (15-20 мин)**
- Пошаговый чек-лист
- Как повторить успех
- Конкретные действия

**6. Результат (5-7 мин)**
- Что получает зритель
- Трансформация, антихрупкость
- Crucibles, высокая нота

**7. Call to action (2-3 мин)**

### Пример из практики
- Сравнение двух компаний в одной нише
- Кейс-исследования

### Плюсы
✅ Наглядность (видно "до/после")  
✅ Мотивация (хочется повторить успех)  
✅ Логичность (понятно, почему именно так)  

### Минусы
⚠️ Кейсы могут "съесть" время у протокола  
⚠️ Может быть слишком линейным (скучно)  
⚠️ Риск потерять динамику  

### Как держать баланс
- Кейсы — короткие вставки (по 2-3 минуты)
- Основное время — протокол (не кейсы)
- Не застревать на деталях кейсов

## Структура 4: Концепция → Принципы → Применение

### Описание
Сначала объясняем новый взгляд на проблему (концепцию), потом принципы, потом как применить.

### Когда использовать
- Обучающее видео (концепция, а не протокол)
- Нужно изменить ментальную модель зрителя
- Тема сложная, требует переосмысления

### Структура

**1. Хук (2-3 мин)**
- Почему старый подход не работает
- Проблема привычного мышления

**2. Концепция (7-10 мин)**
- Новый взгляд на проблему
- Например: "Антихрупкость — это не устойчивость"
- Метафора (пружина vs монолит)

**3. Принципы (10-15 мин)**
- Принцип 1: Постоянные → переменные расходы
- Принцип 2: Одна ставка → диверсификация
- Принцип 3: Защита → наступление
- Каждый принцип + пример

**4. Применение (10-12 мин)**
- Как использовать в бизнесе
- Конкретные шаги
- Кейсы применения

**5. Финал (3-5 мин)**
- Что меняется в мышлении
- Call to action

### Пример из практики
- Видео про антихрупкость
- Концепция "точки роста"
- Стратегическое мышление

### Плюсы
✅ Глубина (меняет мышление)  
✅ Запоминается (концепция + метафора)  
✅ Универсальность (применимо к разным ситуациям)  

### Минусы
⚠️ Может быть слишком абстрактным  
⚠️ Зрителю нужно время на осмысление  
⚠️ Риск потерять практичность  

### Как держать баланс
- Каждый принцип = конкретный пример
- В блоке "Применение" — пошаговка
- Не уходить в философию

## Структура 5: Проблема → Почему так происходит → Методология → Результат

### Описание
Видео-продажа через методологию. Начинаем с боли, объясняем причину, даём методологию.

### Когда использовать
- Продающее видео (вебинар, продукт)
- Нужно не только дать инструмент, но и продать решение
- Есть готовая методология/продукт

### Структура

**1. Хук (2-3 мин)**
- Боль, с которой сталкиваются все
- Узнаваемая ситуация

**2. Проблема (5-7 мин)**
- Что не так
- Типичные ошибки
- Почему привычные подходы не работают

**3. Почему так происходит (7-10 мин)**
- Корневая причина
- Системная ошибка
- Например: "Потому что вы решаете симптомы, а не причину"

**4. Методология (15-20 мин)**
- Вот как мы это решаем
- Наша система/протокол/подход
- Конкретные шаги + примеры
- Кейсы успеха

**5. Что получает человек (5-7 мин)**
- Результат применения методологии
- Трансформация
- Доказательства (цифры, отзывы)

**6. Нативный переход к продукту (2-3 мин)**
- "Если хотите глубже — вот программа"
- Без агрессивных продаж

### Пример из практики
- Вебинары Михаила
- Видео-запуски продуктов
- Signature Talk

### Плюсы
✅ Продаёт без агрессии  
✅ Даёт ценность (методология работает сама по себе)  
✅ Нативный переход к продукту  

### Минусы
⚠️ Риск скатиться в "чистую продажу"  
⚠️ Может быть слишком длинным  
⚠️ Нужен баланс "ценность vs продажа"  

### Как держать баланс
- 80% ценности, 20% продажи
- Методология должна работать сама по себе
- Продукт = углубление, а не единственное решение

# Структуры для видео про мышление / личность (6–8)

Структуры 1–5 выведены из бизнес-выступлений (протокол/кризис). Разбор 10 транскриптов
(@dashkiev.m, июнь 2026) показал: у видео про мышление, психологию и личностный рост — свои
каркасы. Заход у них чаще не через инструмент, а через личную историю или концепт-метафору;
финал — мягче (вопрос/афоризм, а не жёсткий CTA).

## Структура 6: Лестница уровней / социальные фильтры

### Описание
Не пошаговый протокол, а последовательность **стадий роста**: каждый уровень — «социальный
фильтр, через который проходят далеко не все». Развитие через нарастание сложности.
(Реальный пример: «Твой план: от фриланса до большой игры».)

### Когда использовать
- Тема — карьерный/предпринимательский рост, «как перейти на новый уровень»
- Зритель не понимает, почему застрял
- Главный тезис: «застревают не потому, что не способны, а потому что решают задачи нового
  уровня инструментами предыдущего»

### Структура
1. **Хук-трейлер** — серия интригующих вопросов-анонсов («Кого уволят первым? У кого не будет
   проблем в переговорах об оплате?»)
2. **Тезис** — рост идёт скачками через фильтры, а не линейно
3. **Уровень 1 → 2 → … → N** — каждый: в чём суть, какой барьер, какой инструмент нужен
   (толковость → пропускная способность/делегирование → система → осознанный риск →
   безопасность → экзистенциальный смысл)
4. **Финал-афоризм** — без жёсткого CTA, вывод-формула

### Плюсы / Минусы
✅ Зритель находит себя на конкретной ступени · ✅ Понятная карта пути
⚠️ Можно перегрузить уровнями · ⚠️ Слабый CTA (мотивационный жанр)

---

## Структура 7: Эквалайзер / шкала крайностей (каталог измерений)

### Описание
Вводится одна **модель-метафора со шкалой** (диджейский пульт-эквалайзер: у каждого качества
есть «акцентуация» — выгодная форма — и «патология» — крайность). Дальше — не шаги, а
**каталог измерений-«бегунков»**, каждый раскрывается через пару крайностей, и призыв к
самодиагностике. (Пример: «Эквалайзер личности».)

### Когда использовать
- Тема — характер, личные качества, самодиагностика
- Нужно дать зрителю «карту себя», а не инструкцию
- Есть центральная метафора-шкала

### Структура
1. **Концепт-метафора сразу** (без разогрева): «представьте каждого человека как диджейский
   пульт с эквалайзером»
2. **Механика модели**: акцентуация ↔ патология (здоровая vs разрушительная форма качества)
3. **Перебор категорий-бегунков** (самоценность, доверие, границы, проявленность, честность…)
   — каждая = пара крайностей + пример
4. **Призыв к самоанализу** + вопрос в комментарии («какую категорию хотели бы скорректировать?»)

### Плюсы / Минусы
✅ Высокая вовлечённость (зритель примеряет на себя) · ✅ Запоминающаяся метафора
⚠️ Риск рассыпаться на список · ⚠️ Нужен сильный визуал шкалы/пульта

## Структура 8: Две территории / дихотомия + синхронизация

### Описание
Каркас на **контрасте двух миров** и тезисе об их зеркальной связи (внешняя территория —
твёрдое, измеримое; внутренняя — чувства, образы, паттерны; «проблема, не решённая внутри,
проявляется вовне»). Заход — через личную исповедь, а не инструмент. (Пример: «Внешнее и
внутреннее / Я не верил в психологию».)

### Когда использовать
- Тема — психология «для тех, кто верит только в твёрдое» (скептичная аудитория)
- Нужно соединить два полюса (бизнес ↔ внутренняя работа)
- Есть личная история перелома спикера

### Структура
1. **Личная исповедь-узнавание**: «я отрицал всю психологию… пока не обнаружил, что буксую»
2. **Концепция двух территорий** (внешняя/внутренняя) + их синхронизация
3. **Две крайности-ловушки**: застрять во внешнем (пробуксовка) vs «улететь» во внутреннее
   (оторванные «духовные»)
4. **Интеграция**: странность/сбой во внешнем = приглашение посмотреть внутрь
5. **Финал** — мягкий, через образ/афоризм

### Плюсы / Минусы
✅ Берёт скептика через «я был таким же» · ✅ Мостик бизнес↔психология
⚠️ Риск увести в эзотерику (держать «твёрдые» примеры) · ⚠️ Нужен баланс исповеди и пользы

## Как выбрать структуру?

### Вопросы для выбора:

1. **Какая цель видео?**
   - Обучить → Протокол / Концепция
   - Мотивировать → Хаос → Решение
   - Продать → Проблема → Методология

2. **В каком состоянии зритель?**
   - В панике → Хаос → Решение
   - Ищет решение → Протокол
   - Не осознаёт проблему → Ошибка → Контраст

3. **Что есть в материале?**
   - Чёткие шаги → Протокол
   - Яркие кейсы провала/успеха → Контраст
   - Новая концепция → Концепция → Принципы

4. **Какая длина видео?**
   - 20-30 мин → Концепция / Контраст
   - 30-40 мин → Протокол
   - 60+ мин → Методология (вебинар)

## Чек-лист выбора структуры

Для антикризисного протокола:

- [x] Цель: Обучить (дать инструмент)
- [x] Зритель: В кризисе (нужна конкретика)
- [x] Материал: Есть 12-пунктовый протокол
- [x] Длина: 30-40 минут

**Вывод:** Структура 1 (Протокол) или Структура 2 (Хаос → Решение)

**Рекомендация:** Протокол — потому что у зрителя нет времени на эмоции, нужны действия.

---

## Гибридные структуры

Можно комбинировать:

**Пример: Хаос → Протокол**
1. Хук (ошибка)
2. Хаос (кейсы провалов, паника)
3. Контраст (провал vs успех)
4. Протокол (пошаговка)
5. Результат (трансформация)

**Когда использовать:** Зритель в панике + нужна конкретика.

## Итого: Матрица выбора структуры

| Задача | Состояние зрителя | Структура |
|--------|-------------------|-----------|
| Дать инструкцию | Готов действовать | Протокол |
| Успокоить + дать инструкцию | Паника | Хаос → Решение |
| Показать "вилку" | Не осознаёт проблему | Ошибка → Контраст |
| Изменить мышление | Ищет новый подход | Концепция → Принципы |
| Продать методологию | Хочет готовое решение | Проблема → Методология |
| Показать путь роста | Застрял, не понимает почему | Лестница уровней (6) |
| Дать «карту себя» | Хочет разобраться в характере | Эквалайзер / шкала крайностей (7) |
| Зайти к скептику психологией | «Верю только в твёрдое» | Две территории (8) |
