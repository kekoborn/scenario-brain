# Референс визуальных приёмов: Топлес

**Что это.** Каталог визуальных приёмов из разбора 10 выпусков @toplesofficial (по ~70
стоп-кадров на ролик). Топлес — сильнее по инфографике и приёмам, чем наши ролики, поэтому
он референс именно для ВИЗУАЛА (стоп-кадры своих/Дашкиева видео для вдохновения смысла не
дают — у Топлеса дают).

**Главный принцип — НЕ рисуем за команду.** Эти приёмы — банк ТЕКСТОВЫХ идей «что показать»,
а не задание «сгенерируй картинку». ИИ предлагает идею словами («тут показать X на
молекулярном уровне под микроскопом» / «генерация: как выглядел бы мир без растений»),
а творческая команда сама решает, как это воплотить. Авто-рисование загоняет творцов в
рамки и вредит. Приоритет — реальный артефакт-доказательство (скрин/хроника/фото); генерация
и абстракция — крайняя мера. (Согласуется с принципом Этапа 10.)

---

## 1. Базовые регистры кадра (визуальный «код» зрителю)

| Регистр | Что это | Сигнал зрителю |
|---|---|---|
| **Тематическая студия** | говорящая голова в сете под тему (оранжерея для растений, неон-аркада для алгоритмов, «комната-формула E=mc²» для измерений) | основной нарратив |
| **Узнаваемый лук** | один костюм весь выпуск; смена костюма/локации = маркер новой главы | смена темы/главы |
| **Рамка-виньетка** (часто фиолетовая/синяя) | демонстрации, антипримеры, 3D-схемы, архив | «сейчас наглядно/демо» |
| **Full-screen без ведущего** | графика/схема на весь экран | чистый контент-момент |
| **Реклама** | другой UI/фон, фирменные плашки | интеграция (отбита визуально) |

Для нас: завести 2–3 считываемых регистра (студия Михаила vs «демо-рамка» vs реклама),
чтобы зритель мгновенно понимал тип момента.

## 2. Приёмы доказательства (приоритет — реальный артефакт)

- **Реальные скрины приложений/сайтов как пруф:** Tinder, Lamoda с cookie-баннером, YouTube,
  Wikipedia, новостные сайты (7NEWS) с блюром. → показать настоящий интерфейс/страницу.
- **Архивная хроника/документалка** под опровергаемую версию или историч. факт.
- **Цифра как образ, а не график:** «9 962 500» рядами гробов вместо столбиков. → число
  визуализировать предметно.
- **«Я это потрогал»:** ведущий сам у микроскопа/с реквизитом («вырастили опухоль за 3 дня»,
  реальные весы, вакуум-камера). → реальный эксперимент/объект в кадре.
- **Эксперт видеозвонком** в углу — авторитет рядом с шоу.
- **Чужая научная инфографика с копирайтом** (©COMET) — когда нужен авторитетный визуал.

## 3. Метафора-картинка и CGI (когда реального нет)

- **Предметная диорама темы на столе** (песочница с Египтом; макет стопы; флорариум) —
  тема буквально «на столе».
- **3D-CGI метафора** объёма/механизма (вулканы в стеклянном шаре; колодец солёной воды;
  опухоль, пробивающая «кожу из сот»). → описать идею словами, не рисовать.
- **Сплит-скрин** «поп-культура vs реальность» («Интерстеллар vs фото чёрной дыры»).
- **Грим/трансформация ведущего** (состаривание под тему персонализации).
- **Типографика поверх футажа** — крупное слово-акцент.

## 4. Удержание визуалом

- **Геймификатор поверх кадра:** ачивка-плашка («Бутерброд размером с планету»), коллекция
  на карте («пингвинго»), конверт-объект с ответом.
- **Динамика:** активная жестикуляция «руки лепят смысл», жонглирование предметом, движение
  камеры — рушит статику говорящей головы.
- **Глитч/VHS-переходы, вспышки-склейки** — «удары» между блоками.
- **Таймлапс/макро** «красивое о страшном» (личинки комара, нарезка банана).
- **Намеренно грязные ручные кадры** (в тревеле) = маркер документальной правды.
- **Борд сценария как b-roll** — «вот как устроено за кадром».

## 5. Как это попадает в наш визуальный слой (Этап 10)

Каждая viz-идея единицы (Этап 6) и кадр (Этап 10) формулируются ТЕКСТОМ как «что показать»,
и по возможности тянутся к одному из приёмов выше + реальному артефакту:
- Сначала — реальный артефакт-доказательство (скрин/хроника/фото со ссылкой, см. `sources.md`).
- Если нет — предметная диорама / CGI-метафора, описанная словами.
- Указать регистр (студия / демо-рамка / full-screen).
- НЕ генерировать картинку за команду; давать речевую идею-направление.

## 6. Чек-лист визуального приёма (по-Топлесовски)

- [ ] Цифры показаны предметно (образ), а не сухим графиком?
- [ ] Есть геймификатор/сквозной визуальный мотив для удержания?
- [ ] Идея визуала описана ТЕКСТОМ как «что показать», без авто-рисования за команду?
