# ВИЗУАЛЬНЫЙ СЛОЙ: Антикризисный протокол

Бриф для монтажёра/моушн-дизайнера. Визуализируем по смысловым фразам, не по блокам.
Паттерны — из базы скилла (A–F). Стиль: камерный, графитово-фиолетовый, минимализм.
Что НЕ описываем: одежду/внешность ведущего.

---

## БЛОК 1. Хук + анонс (0:00–2:30)

### Кадр 1.1 — «Два режима» (0:00–0:20)
- **ФРАЗА:** «Один и тот же кризис двух собственников вводит в два совершенно разных режима.»
- **ВИЗУАЛ:** A1 (студийная голова) → split-screen
- **КАДР:** Экран делится пополам. Лево — серая, тусклая половина. Право — фиолетовая, контрастная.
- **АНИМАЦИЯ:** Вертикальная линия раскалывает кадр надвое.
- **ПАТТЕРН:** D1 (split-screen) + E2
- **РЕФЕРЕНС:** Netflix-доки, контраст «до/после»

### Кадр 1.2 — «Первый режим: паника» (0:20–0:45)
- **ФРАЗА:** «Замереть… а когда прижмёт — паника: хвататься за всё подряд, тушить пожары, резать наотмашь.»
- **ВИЗУАЛ:** F5 (метафора хаоса)
- **КАДР:** Силуэт мечется между множеством мелких «пожаров», хватается то за одно, то за другое.
- **АНИМАЦИЯ:** Хаотичные рывки, всё дёргается.
- **ПАТТЕРН:** F5 / F1
- **РЕФЕРЕНС:** Стилизованная 2D-анимация тревоги

### Кадр 1.3 — «Второй режим: фокус» (0:45–1:10)
- **ФРАЗА:** «Остановиться. Оглядеться, сфокусироваться на главном… и бить точно в цель.»
- **ВИЗУАЛ:** F5 (метафора фокуса) — контраст к 1.2
- **КАДР:** Тот же силуэт замирает, вокруг туман рассеивается, остаётся одна цель — точный удар.
- **АНИМАЦИЯ:** Из хаоса собирается одна чёткая стрела/луч в цель.
- **АРТЕФАКТ:** Карточка-диптих «режим 1 / режим 2» для соцсетей
- **ПАТТЕРН:** F5
- **РЕФЕРЕНС:** Kurzgesagt (чистый минимализм)

### Кадр 1.4 — Ключевая фраза (1:10–1:25)
- **ФРАЗА:** «Разница не в деньгах и не в везении. Разница в том, в какой режим вы вошли.»
- **ВИЗУАЛ:** B2 (текст крупно)
- **КАДР:** Чёрный экран. «Разница — в режиме» — белым, «режиме» — фиолетовым.
- **АНИМАЦИЯ:** Слова появляются по одному, «режиме» пульсирует.
- **АРТЕФАКТ:** Текстовая карточка (якорь)
- **ПАТТЕРН:** B2

### Кадр 1.5 — Анонс из 4 пунктов (1:25–2:30)
- **ФРАЗА:** «Первое — деньги… Второе — что резать… Третье — команда… Четвёртое — с чего начать завтра.»
