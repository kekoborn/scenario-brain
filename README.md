# Scenario Brain — генератор сценариев видео в стиле Михаила Дашкиева

Управляемый пайплайн, который ведёт от идеи до **готовых документов**: сценарий в **DOCX**
(с выбранным названием) + **HTML-сториборд** визуализации для монтажёра. Заточен под стиль
и TOV Михаила Дашкиева, аудитория — собственники бизнеса.

Главный принцип: **не писать сценарий «простынёй», а вести по этапам** — с глубоким
интервью, проверенным research (без фабрикаций), ревью блоков и финальной упаковкой.

## Пайплайн (этапы 0–12)

0. **Discovery-интервью** — глубокое погружение. Если расшивки нет — скилл проводит её сам
   (12 тем: метод, аудитория, боль, кейсы, истории, метафоры, возражения…). Вопросы —
   кнопками (нажатие), а не «ответь буквой».
1. **Research** — расхождение → схождение. Только свежие (текущий/прошлый год) и
   перепроверенные факты. Фабрикации запрещены.
2. **Сверка с TOV** · 3. **Выбор структуры** · 4. **Архитектура** (блоки)
5. **Хуки** (5 вариантов → выбор) · 6. **Генерация всех блоков**
7. **Ревью** — блоки выдаются в **HTML-интерфейсе** (статусы на русском, комментарии,
   копирование ответов в JSON для ИИ), а не текстом.
8. **Правки** · 9. **Финальная сборка**
10. **Визуальный слой** — `visual-brief.md` + интерактивный `storyboard.html`.
11. **Название** — генерация → выбор → доработка.
12. **Выдача документов** — **DOCX** (сценарий + название) + **HTML** (сториборд).

Полный образец результата — в `examples/antikrizisny-protokol/`.

---

## Требования

- **DOCX-сборка:** `python3` + `python-docx` (`pip install python-docx`).
  Опционально для конвертаций: `pandoc`, LibreOffice (`soffice`).
- Для research-этапа — доступ ассистента к веб-поиску.

## Установка в Claude

### Вариант 1 — Claude Code (рекомендуется, полный функционал)
Скилл работает как нативный Claude Code skill — с интерактивными вопросами
(AskUserQuestion), генерацией HTML/DOCX и файловыми артефактами.

```bash
# клонировать в папку скиллов
git clone git@github.com:kekoborn/scenario-brain.git ~/.claude/skills/scenario-brain
# поставить зависимость для DOCX
pip3 install python-docx
```

Запуск в сессии:
```
/scenario-brain
```
или: «Сделай сценарий видео про <тему>».

> Обновление: `cd ~/.claude/skills/scenario-brain && git pull`.

### Вариант 2 — Claude.ai (Projects)
1. Создай **Project**.
2. В **Project instructions** вставь содержимое `SKILL.md`.
3. В **Project knowledge** загрузи файлы из `knowledge-base/`, `research-rules.md`,
   `templates/*.md` (и при желании `examples/`).
4. Запускай: «Веди меня по этапам Scenario Brain. Тема: …».

> Ограничения вне Claude Code: интерактивные кнопки и автогенерация файлов недоступны —
> ассистент задаёт вопросы текстом, а HTML/DOCX выдаёт кодом для самостоятельного
> сохранения (см. ниже).

## Установка в ChatGPT

ChatGPT не поддерживает нативные «скиллы», поэтому используем **Custom GPT** или **Project**.

### Вариант 1 — Custom GPT (рекомендуется)
1. **Explore GPTs → Create → Configure.**
2. В **Instructions** вставь полный текст `SKILL.md`. В начало добавь адаптацию:
   > «Ты — Scenario Brain. Следуй этапам ниже. Вопросы с вариантами задавай нумерованным
   > списком (1/2/3) и проси выбрать номер. HTML-артефакты (review, storyboard) и DOCX
   > выдавай как блоки кода/файлы для скачивания. Опирайся на загруженные knowledge-файлы.»
3. В **Knowledge** загрузи: `knowledge-base/*.md`, `research-rules.md`, `templates/*.md`,
   `templates/build_docx.py`, и образец `examples/antikrizisny-protokol/scenario-final.md`.
4. Включи **Web Browsing** (для research) и **Code Interpreter** (для сборки DOCX через
   `python-docx`).
5. Сохрани. Запуск: «Сделай сценарий про <тему>».

### Вариант 2 — Projects (ChatGPT)
1. Создай Project, загрузи те же файлы в его файлы.
2. В инструкции проекта вставь `SKILL.md` + адаптацию выше.

### Отличия от Claude Code
- **Кнопки → номера.** Вместо нажатия — выбор номера в списке.
- **Файлы.** HTML (review/storyboard) и DOCX ChatGPT отдаёт через Code Interpreter
  (скачиваемые файлы) — для DOCX используется тот же `templates/build_docx.py`.
- Логику этапов это не меняет — меняется только способ ввода/выдачи.

## Лицензия / приватность
Приватный репозиторий. Все референсы (TOV, структуры, визуальные паттерны, формулы,
эталонный прогон) включены в репозиторий — внешних зависимостей для логики нет.
