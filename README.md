## Что это

Полный конвейер создания сценариев видео в стиле Михаила Дашкиева:

**11 этапов:**
0. **Discovery-бриф** — адаптивный опросник (5-7 мин вместо 30)
1. **Research** — расхождение → схождение (20+ источников → must-have инсайты)
2. **Сверка с TOV** — определить стиль Михаила
3. **Выбор структуры** — из 5 проверенных архитектур
4. **Архитектура** — разбить на блоки
5. **Генерация хуков** — 5 вариантов хука → выбор лучшего → это Блок 1
6. **Генерация блоков** — писать остальные блоки с интеграцией research
7. **Ревью** — статусы OK/EDIT/WEAK/CUT
8. **Правки** — переписать проблемные блоки
9. **Финальная сборка** — собрать всё вместе
10. **Визуальный слой** — ЧТО/ЗАЧЕМ/ПОЧЕМУ ЗДЕСЬ + B-roll suggestions
11. **Названия** — 10 вариантов названия для A/B теста

**Результат:** Готовый сценарий 40+ минут за 2-3 часа работы (вместо 3 дней).

**Ключевое отличие v1.9:** Хуки генерируются ПОСЛЕ архитектуры, но ДО генерации блоков. Выбираем лучший из 5 вариантов — он становится началом сценария.

## База знаний

### TOV (Tone of Voice) Михаила Дашкиева

**Источник:** 10 транскриптов видео (793К символов)

**Ключевые находки:**
- Объясняет через конкретные кейсы с именами/цифрами
- Аргументирует через управление, модели, деньги, систему
- Прямой, но не агрессивный
- Метафоры из физического мира
- 15+ характерных речевых конструкций
- Список того, что НЕ подходит (ИИ-штампы, канцелярит)

### Структуры видео

**Источник:** Разбор тех же 10 видео по архитектуре

**5 повторяющихся архитектур:**

1. **Экспертный разбор с референсом**  
   Когда: концептуальные фреймворки через авторитет  
   Пример: "Главное и второстепенное" (Голцов/Кузнецов)

2. **Case Study / Бизнес-экскурсия**  
   Когда: показать успішний бізнес изнутри  
   Пример: "Стоматология" (9,840 операций, 6M RUB на рекламу)

3. **Развенчание мифов**  
   Когда: сломать популярное заблуждение  
   Пример: "Как на самом деле развиваться" (5 мифов)

4. **Протокол / Checklist**  
   Когда: дать пошаговую инструкцию  
   Пример: "Протокол трансформации" (7 шагов)

5. **Backstage / Под капот**  
   Когда: показать технологию/процессы  
   Пример: "Контент-завод" (150 сценариев/мес)

### Вариант Б: Вручную

1. Скопировать `templates/brief-template.md` → `sessions/[проект]/brief.md`
2. Заполнить бриф
3. Прочитать `knowledge-base/TOV-analysis.md` и `STRUCTURES-analysis.md`
4. Выбрать структуру
5. Создать архитектуру (список блоков)
6. Писать блоки по шаблону `templates/block-template.md`
7. Редактировать через статусы
8. Собрать финал

## Статусы блоков

| Статус | Значение | Действие |
|--------|----------|----------|
| `OK` | Берём как есть | Сохранить блок |
| `EDIT` | Мысль ок, переписать | Сохранить смысл, изменить формулировку |
| `WEAK` | Блок слабый | Предложить 2-3 новых захода |
| `CUT` | Удалить | Проверить логику сценария |
| `MOVE` | Перенести | Предложить новое место |
| `NOT_TOV` | Не похоже на Михаила | Переписать по TOV-базе |
| `ADD_PROOF` | Нужен пример | Добавить кейс/факт/цифры |
| `ADD_ACTION` | Нужно действие | Добавить практический шаг |
| `TOO_LONG` | Слишком длинно | Сократить до сути |
| `TOO_ABSTRACT` | Слишком абстрактно | Добавить конкретики |

## MVP vs Полная версия

### MVP (текущая версия)

✅ Брифование  
✅ Сверка с TOV  
✅ Выбор структуры  
✅ Сценарий по блокам  
✅ Редактура по статусам  
✅ Финальная сборка  

### Полная версия (будущее)

⏳ Deep research по теме  
⏳ Конкурентный анализ  
⏳ Визуальный слой (монтаж, анимации)  
⏳ Интеграции (лид-магниты, CTA)  
⏳ Модуль хуков и названий  
⏳ Fine-tuning  
⏳ YouTube-статистика  
⏳ Автообучение на правках
